## 🚀 如何上傳到 GitHub 並在不同裝置上使用（全圖形化免指令教學）

為了讓您在**教室電子白板、辦公室桌機、個人平板或手機**隨時開啟都能瀏覽與操作，建議將本專案發布至免費的 **GitHub Pages**。

### 步驟 1：建立 GitHub 儲存庫 (Repository)
1. 前往 [GitHub 官方網站](https://github.com/) 註冊或登入帳號。
2. 點擊右上角的 **「+」** ➔ 選擇 **「New repository」**。
3. 填寫儲存庫資訊：
   - **Repository name**：輸入例如 `xining-502-kingdom`。
   - **Visibility**：請務必選擇 **「Public」**（免費版 GitHub Pages 需設為 Public）。
   - 其餘選項保持預設，點擊最下方的 **「Create repository」**。

### 步驟 2：免裝指令，網頁端直接拖曳上傳
1. 在剛建立好的 GitHub 專案頁面中，點擊 **「uploading an existing file」**（或「Add file」➔「Upload files」）。
2. 打開您電腦中的 `d:\AI代理人\xining-kingdom` 資料夾，選取下列核心檔案，直接**拖曳**進瀏覽器上傳視窗中：
   - `index.html`（主頁面）
   - `app.js`（核心引擎與資料）
   - `ui.js`（畫面互動邏輯）
   - `styles.css`（明亮金黃樣式表）
   - `.nojekyll`（防止 GitHub Pages 忽略設定檔）
   - `README.md`（說明文件）
3. 拖曳完畢後，在下方 Commit 欄位點擊綠色的 **「Commit changes」** 按鈕完成上傳。

### 步驟 3：啟用 GitHub Pages 免費靜態託管
1. 點擊專案上方的 **「Settings」**（設定）分頁。
2. 在左側選單中找到並點擊 **「Pages」**。
3. 在 **「Build and deployment」** 區塊中：
   - **Source**：選擇 `Deploy from a branch`。
   - **Branch**：下拉選單選擇 `main`，右側資料夾選擇 `/ (root)`。
   - 點擊 **「Save」** 儲存。
4. 稍等約 1 ~ 2 分鐘，重新整理頁面，最上方會出現綠色提示與專屬全球網址：
   > 🌐 **您的專屬網址**：`https://<您的GitHub帳號>.github.io/xining-502-kingdom/`

## ☁️ Google 帳號跨裝置雲端資料即時同步使用方法

現在系統已全面升級為 **「輸入 Google 帳號 (Gmail) 即可直接同步」**！無論在手機、平板、學校電腦或家裡筆電，只要設定**相同的 Google 帳號**，資料就能全自動互通。

### 方式 1：一鍵複製專屬手機同步網址（手機免打字、最推薦）
1. 在電腦上打開系統，點擊右上角導航列的 **「[🟢 雲端同步]」** 按鈕。
2. 在「設定同步的 Google 帳號」欄位輸入您的 Gmail（例如：`yourname@gmail.com`），點擊「儲存並同步」。
3. 點擊下方的 **「📋 複製連結」**，系統會複製專屬帶有您 Google 帳號的網址（例如：`https://.../?google=yourname@gmail.com`）。
4. **將此網址透過 LINE 發送到您的手機或平板打開**：
   - 手機一打開就會**自動綁定該 Google 帳號**，並立刻載入最新全班存檔！

### 方式 2：教室 / 家中同一 Wi-Fi 區域網路同步（免外網直連，最穩定）
- 在教室用筆電雙擊 `啟動西寧小小兵王國.bat`。
- 伺服器視窗會顯示例如：`👉 手機查閱網址：http://192.168.50.71:3000`。
- 手機連上同一教室 Wi-Fi，打開該網址，手機與電腦即時直連同步！

### 方式 3：綁定 Google Apps Script 官方免費雲端硬碟庫（跨 4G/5G 外網永久免費）
- Google 提供每位用戶免費且無限期的 **Apps Script**，可作為您的個人專屬雲端資料庫：
  1. 前往 [script.google.com](https://script.google.com/) 點擊「+ 新專案」。
  2. 在系統同步彈窗中點擊 **「📋 一鍵複製 15 行 Google 雲端腳本代碼」**，貼上至 Apps Script。
  3. 點擊右上角「部署 ➔ 新增部署作業 ➔ 網頁應用程式 (存取權: 任何人)」，複製產生的網址貼入系統中儲存。
  4. 從此無論身在何處，只要輸入 Google 帳號，手機就能透過 Google 官方雲端即時雙向同步！

### 方式 4：本機備份與還原（100% 絕對成功）
- 電腦端點擊 **「💾 匯出本機備份 (JSON)」** 下載檔案並透過 LINE 傳到手機。
- 手機端點擊 **「📂 匯入備份檔」**，一秒完整還原全班打卡、作業、座位與點數！

## 💺 教室座位表 (5x6 格局) ＆ 幸運抽籤點名指南

點擊導航列的 **「💺 教室座位表」** 即可進入全班座位管理視圖。

1. **5 排 x 6 列內閣格局**：
   - 專為五年二班 27 位大臣量身定制（前 27 格為席位，最後 3 格為備用空席）。
   - 黑板講台方向明確標示（面向學生視角），兩側標記前門、後門與採光窗戶。
2. **直覺更換座位**：
   - **點選互換**：點一下大臣 A 的座位（會亮金框），再點一下大臣 B 的座位（或空席），兩人立刻對調！
   - **拖曳互換**：支援滑鼠或觸控拖曳座位卡片，直接拉到目標席位放下即完成調位。
3. **即時狀態透視**：
   - 每張座位卡清晰呈現：座號、姓名、今日到校時間（如 `到 07:28` / `⚠️ 遲到` / `🏖️ 請假`）、下課通行燈號（🟢/🟡/🔴）、今日愛班服務標籤（`🧹 愛班`）與榮譽金幣點數。
4. **🎲 幸運大臣輪盤隨機抽籤（課堂點名神器）**：
   - 點擊 **「🎲 幸運大臣抽籤點名」**，系統自動過濾全天請假缺席大臣。
   - 伴隨輪盤快速跳動音效，在全班座位網格間高速旋轉光圈，逐漸減速後精準停在天選大臣席位！
   - 伴隨皇室號角 fanfare 與全螢幕彩色拉炮揭曉幸運大臣，課堂提問與發表氣氛超熱烈！
5. **🔀 隨機洗牌換位 & 🔄 一鍵重置**：
   - 每月換座位時可點擊「🔀 隨機重新排位」，全班 27 人瞬時隨機分派。
   - 想恢復座號依序排列時，隨時點擊「🔄 重置座號順序」。
6. **🖨️ A4 講桌規格友善列印**：
   - 點擊「🖨️ 列印 A4 座位表」，系統以簡約白底高對比格式排版，一鍵列印張貼於導師講桌。

## 🤫 安靜提醒與王國音量守護者指南

點擊頂部導航列的 **「[🤫 安靜提醒]」** 按鈕開啟：

1. **🔔 皇室全班安靜令（課堂常規凝聚器）**：
   - 點擊「發布全班安靜令」，系統立即合成播放**空靈清脆的柔和水晶鐘聲**。
   - 螢幕自動彈出醒目莊嚴的**全螢幕安靜敕令動畫**（「全班請肅靜！請全體大臣即刻放下手邊事務，目光注視黑板」），免去老師大聲喊口令的疲累，3 秒後或點擊任意處自動淡出。
2. **🎙️ 王國即時音量分貝監測儀（音量守護者）**：
   - 點擊「開啟音量監測」，即刻啟用教室麥克風即時取樣音量分貝（RMS 震幅）。
   - 三段色彩動態長條圖：
     - 🟢 **0% ~ 40% 寧靜專注**：適合自主閱讀、課堂聽講。
     - 🟡 **41% ~ 70% 輕聲細語**：適合分組低聲討論。
     - 🔴 **>70% 喧嘩超標**：長條轉紅並閃爍警示文字，提醒全班壓低聲量。
   - 可依班級環境自訂「喧嘩警戒門檻」滑桿（40% ~ 95%）。
   - 🔒 **100% 本地安全隱私**：所有音量運算均在瀏覽器前端本地即時運算，**絕對不錄音、不存檔、不傳輸至任何雲端伺服器**，保障全班學童隱私！
